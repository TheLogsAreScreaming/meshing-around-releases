# Meshing Around releases

Downloads of the Meshing Around desktop app for Intel Macs. The source code is at
[TheLogsAreScreaming/meshing-around](https://github.com/TheLogsAreScreaming/meshing-around).

Each release lists what was and wasn't tested. Builds are unsigned betas: on first launch,
Control-click the app, choose **Open**, then confirm.
